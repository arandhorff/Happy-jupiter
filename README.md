# Para mi Júpiter ✨💐

Una experiencia interactiva creada con mucho cariño, código y paciencia para celebrar un cumpleaños muy especial.

## Características
* **Modo 3D Real (Three.js WebGL):**
  * Modelado botánico tridimensional con OrbitControls (giro 360°, inclinación y zoom interactivo).
  * 16 variedades botánicas (Rosas en espiral áurea, Tulipanes, Peonías, Dalias, Girasoles, Claveles, Orquídeas, Lirios, Follaje de Eucalipto y Helechos).
  * Materiales PBR botánicos aterciopelados con gradientes procedurales y codificación de color sRGB / ACES Filmic Tone Mapping sin quemado de color.
* **Modo 2D Ilustrado:**
  * Arte botánico vectorial sobre HTML5 Canvas con animación de florecimiento.
* **Estudio de Armado de Ramo:**
  * Selección personalizada de entre 3 y 10 flores con sus propios colores pastel y botánicos.
  * Ensamblaje en cúpula floral 3D con haz de tallos y lazo satinado rosa.
* **Audio y Efectos Mágicos:**
  * Síntesis de sonido Web Audio API (campanitas mágicas y arpegios).
  * Lluvia interactiva de pétalos que responden al movimiento y tacto.
  * Tarjeta y dedicatoria personalizada.

## Cómo desplegar en GitHub Pages
1. Ve a **Settings** en el repositorio de GitHub.
2. En la sección lateral izquierda, haz clic en **Pages**.
3. En **Build and deployment > Branch**, selecciona la rama `main` y la carpeta `/(root)`.
4. Haz clic en **Save**. ¡En pocos segundos la página estará disponible en la web!
